## Interpretation

Field accuracy compares case-insensitive trimmed strings and amounts within 0.01; missing labels are scored against explicit nulls. Document accuracy requires invoice number, date, supplier, total, and currency all match. Line-item accuracy requires the full array to match. Spreadsheet ledger matches are reported per file in results.json, separately from invoice accuracy. Timing is measured inside the worker, including parsing, extraction and validation, excluding queue wait. Wall times are also retained.

The set includes clean synthetic layouts, three real Tesseract image formats, a scanned PDF, a skewed/blurred image, multi-sheet Excel, legacy XLS, CSV, missing fields, invalid arithmetic, conflicting copies, a blank PDF, a corrupted PDF and a 1000-page digital PDF. Similar layouts make this a reproducibility check, not a generalization benchmark. OCR can lose separators, numbers and line items on skewed images; the deterministic offline parser only recognizes explicit English labels.

Cross-document validation is refreshed after the entire set is uploaded, so final review states include later ledgers and conflicting copies. Documents with valid extraction may still need review. A non-failed processing rate must not be interpreted as verified accuracy.

## Reproduce

Run the fixture generator, then `npm run eval`. No API key is required. To measure provider-backed extraction explicitly set `EVAL_EXTRACTION_MODE=openai` with an API key. Results are never substituted with estimates.
